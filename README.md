# Редактор математических формул с вычислительным ядром

Учебно-исследовательская работа (УИР). Интерактивный редактор математических
формул на C++/Qt с собственной иерархической моделью (AST), вёрсткой через
движок `mfl` (FreeType + HarfBuzz) и вычислительным ядром на базе SymPy.

## Структура

```
project/        — рабочий код (собираемый проект)
    formula_widget/   — редактор: виджет Qt, AST-курсор, семантика, CAS-мост
    mfl/              — движок вёрстки математических формул
материалы/      — вспомогательные материалы:
    *.docx            — пояснительные записки, план, отчётные материалы
    *.pdf             — бланки и шаблоны
    *.py              — генераторы документов (python-docx)
    *.svg, *.png      — рисунки и скриншоты
    *.md              — рабочие заметки и планы
```

## Сборка и запуск

Требования: CMake ≥ 3.16, Qt6, FreeType, HarfBuzz, компилятор C++20.
Для вычислительного ядра: `python3` с пакетами `sympy`, `numpy`, `matplotlib`.

```bash
cd project/formula_widget
cmake -S . -B build
cmake --build build
ctest --test-dir build        # автотесты (9 наборов)
./build/formula_widget        # запуск (из каталога formula_widget — там шрифты)
```

## Возможности

- Иерархическое редактирование: дроби, корни, степени/индексы, интегралы, суммы,
  матрицы, акценты, ограничители, системы уравнений.
- Навигация: стрелки, Tab/Shift+Tab по полям структур, переход числитель↔знаменатель.
- Горячие клавиши: Ctrl+Z/Y (отмена/повтор), Ctrl+C/X/V (буфер), Ctrl+A, Ctrl+R.
- Вычислительное ядро: вычисление, упрощение, дифференцирование, интегрирование
  и построение графиков функций (кнопки панели «Вычисления»).
